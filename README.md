# 3A進路ノート（公開アプリ）

生徒42名の進路情報を、教員の端末内で管理するHTMLアプリです。公開ファイルに生徒の氏名・志望校・得点・判定・個人別受験計画は含めていません。

## 更新前に

現在使っているノートの「データ管理」から全データJSONを保存してください。公開版を開いた後、同じ画面からJSONを復元すると、端末内のデータとして利用できます。配信HTMLやGitHubへ入力データを自動送信・同期する処理はありません。ブラウザー・端末が変わる場合もJSONで引き継ぎます。

## 主な機能

- 番号から志望校・模試別判定・10科目の共通テスト得点・受験計画を表示
- 生徒別の受験計画を受験日・各種締切・大学名などで並べ替え
- 手動の上下移動、生徒ごとの並び順保存、表示順のExcel出力
- 元ファイルのプレビュー、一括入力、JSONバックアップと復元

大学公式資料は生徒データと独立した公開情報です。南山大学のPDFは公式URLから開きます。資料年度・方式・確認状況を必ず確認してください。

## データの保管

生徒データ入りHTML・全データJSON・成績Excelをこの公開リポジトリへコミットしないでください。データの保存先はブラウザーのlocalStorageとIndexedDBです。保存容量不足やブラウザーデータ消去に備えて、JSONを別に保管してください。非公開保管用リポジトリも、自動同期ではありません。

## 検証

データ処理・DOM環境での操作テストを実施しています。実ブラウザーの描画とスマートフォンの操作は未確認です。
